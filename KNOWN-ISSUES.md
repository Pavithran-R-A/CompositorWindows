# Known issues

The Windows preview follows the observable behavior of Compositor 1.0.4 through 1.4.5. The dependency pin remains `a19db9011282399785dc18efcfded904627bdcc2`. Full Mac equivalence, reciprocal project exchange, and Photoshop compatibility have not been verified. The Metal compositor is not ported.

| Area | Limitation |
| --- | --- |
| Large soft brushes | On a Core Ultra 9 285K / RTX 5070, 4000 px documents with 800 px soft brushes measured 38.6–50.4 ms p95 event-to-DwmFlush latency. Worst stroke start/release was 427/522 ms. Background CPU load was present. This is not a 60 Hz or physical-input latency guarantee. |
| Foreground removal | Hair, fur, and dandelion edges can retain background color. Transparent bubbles fail the quality case; Advanced is not uniformly better. An eight-image run produced seven masks and one no-subject result, with inference around 2.1–2.2 seconds and peak memory around 1.4 GiB. Inspect and refine masks. Object selection on the wand uses the same BiRefNet matte and has the same hair limit. |
| Imports and Camera Raw | PSD and PSB import is 8-bit or 16-bit RGB. 16-bit RGB pixels stay 16-bit through save, reopen, gradients, fills, and PNG export. Other pixel edits drop that layer to 8-bit. JPEG export is 8-bit. CMYK is refused. A failed layer parse falls back to the merged composite. SVG is rasterized on import. RAW development needs a WIC codec and is a separate step from the Camera Raw filter. Camera Raw Filter has no camera profile or kelvin presets. Guided Upright is a two-line heuristic, not a vanishing-point fit. Guide lines stay on the preview until Clear Guides or the filter closes. Geometry is a CPU homography rather than Core Image. The grade is not stored in the project file. |
| Regression discrepancies | The last full normal run at `8ae00f7` passed 1022/1061 (39 failures, each classified): 22 subject_input cases are blocked on maintainer-published frozen fixtures; 6 retained discrepancies concern thumbnail cursor behavior, Gaussian border alpha, a deleted upstream cursor observer, M/L shortcut expectations (the pinned SelectionTests source cycles the marquee shape and lasso kind on repeated M/L presses; the Windows tool keys switch tools without cycling — matching the frozen source needs an upstream behavior decision), and a frozen Levels cancellation reference containing a repaired defect. The remaining 10 are deterministic failures diagnosed in the audit (retouch sparse-vs-dense WARP pixel equivalence, eye-swipe press routing, two drop/open-batch cases from post-0.1.8 upstream commits, and the interaction family) that need a development-host run to separate product regression from environment sensitivity. These remain failures, not parity evidence. |
| Sanitizer shutdown | The last full ASAN run at `8ae00f7` passed 998/1061 with zero AddressSanitizer memory-error reports; the 63 failures are the release-build discrepancies plus 24 timing/timeout failures from ASAN's 2–3× slowdown on an 8 GB host. The historically intermittent allocator wait during CRT shutdown did not reproduce; the cause remains unresolved. The distributed executable uses the normal build. |
| Signing and updates | Downloads are unsigned. Installing updates is manual; the application ignores development update feeds. A daily check (can be turned off) reads the latest stable GitHub release and only links to its page; it does not verify the downloaded package. Development keys/helpers are excluded from runtime packages. |
| Dialog chrome | `src/ui/VisualStyle.cpp` moves each dialog's layout into a content widget after polish. That clipped the Focus Stack error box, output chooser, and progress window (empty body, hidden Cancel), which now opt out with the `studioChrome` property. An audit of the remaining dialogs found the same failure in every `QProgressDialog`, so the chrome handler now keeps Qt's layout for that class, and the docked Camera Raw dialog reserves the title row's height. Dialogs that size themselves from external geometry are the remaining risk class. |
| Small drags near snap lines | Fixed at `9d4f7f4`: a marquee drag whose snapped box collapses to nothing now falls back to the raw pointer, so a real drag always selects. Snapping itself is unchanged; Ctrl still suppresses it. |
| Foreground model startup | The foreground-removal model is loaded lazily on a worker thread the first time subject removal runs, with progress and cancellation; it does not delay editor startup (window-visible 1.1–1.9 s on the tested 8 GB host). The `--update-health-check` command intentionally loads the model to verify it, which is why that check takes longer. |
| Coverage | Installation has been checked on the development machine. Fresh Windows environments, physical pens, multiple monitors, Narrator, high contrast, IME, and a wider range of GPUs have not been verified. |

The former blend-preview test harness crash was repaired; it is separate from the intermittent ASAN shutdown issue. No known ordinary-use crash or project corruption is being accepted as an intentional limitation.

See [validation](VALIDATION.md) for the measured checkpoints. Please [report problems](https://github.com/IAmTheBlurr/CompositorWindows/issues) with the preview version and reproduction steps.
